# Wikipedia Web Scraper

A Python project that uses the Wikipedia MediaWiki API to retrieve parsed article HTML and build a reader-style HTML page.

## Technologies
- Python
- Jupyter Notebook
- Requests
- Wikipedia MediaWiki API
- HTML and CSS

## Requirements
- Python 3
- Jupyter Notebook
- requests

## Installation
```bash
pip install requests
```

## How to Run
1. Open Web_Scrapping.ipynb in Jupyter Notebook or Google Colab.
2. Run the notebook cells.
3. Use the functions to retrieve and format Wikipedia article content.

## Data Source
Wikipedia MediaWiki API: https://en.wikipedia.org/w/api.php
